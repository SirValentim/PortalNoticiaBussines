# Codex Project Context

## Projeto

Plataforma CMS editorial modular em Golang, iniciada pelo portal Inhumas em Foco e preparada para evoluir para multiplos portais, como LaMafiaMusic, GoiasNews e futuros produtos SaaS.

## Objetivo

Criar um core reutilizavel para portais editoriais, com configuracao por tenant, branding independente, painel administrativo, conteudo editorial, midia, automacao, SEO, modulos comerciais e operacao segura.

## Arquitetura Atual

- Monolito modular em Go.
- HTTP server em `cmd/web`.
- Worker de jobs em `cmd/worker`.
- MCP editorial em `cmd/mcp`.
- Templates HTML server-side com HTMX leve.
- Repository central para persistencia.
- Services pontuais para auth, usuarios, editorial, comercial, automacao, storage e IA editorial.
- Configuracao por env em `internal/config`.
- Branding multiportal via `TenantBrandingConfig`.

## Regras

- Evoluir incrementalmente, sem reescrever o sistema.
- Preservar compatibilidade com SQLite local e PostgreSQL futuro.
- Nunca alterar migrations antigas; criar novas migrations versionadas.
- Handlers devem orquestrar HTTP; regras de negocio devem migrar para services.
- Repository continua sendo a fronteira com banco ate a modularizacao gradual.
- Branding, configuracoes e assets de portal devem ficar fora de valores hardcoded.
- Todo novo modulo deve documentar responsabilidades, tabelas, rotas e riscos.

## Prioridade Atual

1. Consolidar o cerebro do projeto em `docs/ai-context`.
2. Documentar arquitetura e dividas tecnicas.
3. Preparar refatoracao gradual para core reutilizavel.
4. Evitar mudancas estruturais grandes antes de criar testes de seguranca para rotas criticas.
